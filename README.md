# Sensor Deck for Galaxy S25

Galaxy S25本体の物理センサーを、広告なしでリアルタイム表示するAndroidアプリです。

## 表示項目

- 気圧（hPa）、短期履歴グラフ、標準大気圧基準の推定高度
- 方角、地磁気
- 3軸加速度、3軸ジャイロ
- 照度、近接距離
- GPS/QZSSの緯度・経度・高度・速度
- GPS専用ボタンから開く全画面OpenStreetMap
- 現在地マーカー、現在地へ戻る操作、ズームボタン
- GPS位置に基づく現在・今日・明日の天気予報
- 画面上部に現在地・現在気温・体感温度・最高／最低気温を大きく表示
- 72時間（約3日）予報を1時間単位で取得し、指の移動距離に合わせて連続スクロール
- 霧・小雨・雨・雪・雷を直感的な天気絵文字で表示
- 予報スワイプは時間単位へ吸着せず、指を離した後も速度に応じた慣性で移動
- 日付が変わる時刻には月日を表示
- スワイプ中は天気部分だけを画面更新周期に同期して描画し、センサー更新の割り込みを抑制
- ウェザーニュースは予報スクロールと分離した専用ボタンから表示
- Bluetooth LE・Wi-Fiの電波強度を一覧表示する電波ファインダー
- 端末を回して測定した電波強度を時刻同期・ノイズ除去し、複数方向の測定から矢印と推定精度を表示
- 接続中Wi-Fiは方向スキャン中約0.35秒・通常約0.7秒間隔で測定し、通常のWi-Fiスキャン制限を受けにくい高精度追跡に対応
- Wi-Fi RTT対応アクセスポイントは電波の往復時間から距離を実測し、非対応Wi-Fi・Bluetoothは推定距離の範囲を表示
- Bluetooth広告の送信強度・全対応PHY・外れ値除去を利用し、Wi-Fi／Bluetoothとも1m位置での距離校正に対応
- 方向スキャンは最初の測定から仮方向を即時反映し、回転速度と端末の傾きを除外して精度を改善
- 天気と現在地名を並列取得して初期表示を高速化
- 前回の72時間予報を起動直後に即表示し、GPS・ネットワーク位置を使って裏で最新予報へ更新
- Galaxyの天気アプリを意識した空色背景・大きな現在気温・独自天気イラスト・4日間予報を表示
- 充電接続時のGalaxy風リングアニメーションと、いつでも開ける専用充電モニターで電池側の推定W・A・Vを表示
- Galaxyホーム画面用のサイズ可変天気ウィジェット（2×1では現在の天気のみ）
- 釣りモード：波高・波向・周期・風速・海水温・潮位変化
- GPS座標を自治体コードへ変換し、ウェザーニュースの現在市区町村ページを直接表示
- S25本体に非搭載の温度・湿度・心拍・水深センサーを明示

## プライバシー

地図タイルの取得と天気予報の取得にインターネット接続を使います。天気予報の取得時は現在の緯度・経度をOpen-Meteoへ送信します。位置情報を含む測定値をアプリ内には保存しません。

## ビルド

Android Studioでこのフォルダを開き、SDK 35を導入して `Build > Build APK(s)` を実行してください。生成先は `app/build/outputs/apk/debug/app-debug.apk` です。

## 測定上の注意

推定高度は標準海面気圧 1013.25 hPa を基準にしているため、天候によって実際の標高とずれます。正確な高度を得るには、その場所の海面更正気圧で校正する機能の追加が必要です。
